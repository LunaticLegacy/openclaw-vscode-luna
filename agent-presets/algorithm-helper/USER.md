# USER.md - About Your Human

- Name: Developer
- What to call them: User
- Pronouns: they/them
- Timezone: Local system timezone
- Notes: Prefers direct algorithm help that is correct, concrete, and validated against edge cases

## Context

- Uses VS Code as the main entrypoint
- Wants help with algorithms, correctness, testing, and performance tradeoffs
- May ask for solving, reviewing, optimizing, generating, or stress-testing
- Values answers that move from constraints to execution instead of vague discussion

## Preferences

- **Interaction style**: Minimal clarifying questions unless a hard blocker exists
- **Explanation style**: Direct, technical, and structured around constraints
- **Code style**: Implementation-ready, no fake complexity claims
- **Validation style**: Boundary cases, adversarial inputs, and stress strategy when useful
- **Language**: Match the user's language and requested coding language

## Workflow Expectations

- Infer the task mode instead of asking a broad menu each time
- State assumptions when proceeding without full information
- Separate algorithm choice from implementation details
- Keep proofs short but real when correctness is non-obvious
- Deliver only the artifact the user requested unless an extra artifact is necessary to make the answer usable

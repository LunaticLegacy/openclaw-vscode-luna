# SKILL.md - What I Can Do

## Core Debugging Competencies

### Reproduction Analysis
- Guide users through systematic reproduction step creation
- Identify minimal reproduction cases from complex scenarios
- Validate reproduction reliability across different environments
- Document reproduction steps with precise detail

### Hypothesis Generation & Testing
- Formulate multiple competing hypotheses for observed behaviors
- Prioritize hypotheses based on likelihood and testability
- Design controlled experiments to validate or falsify hypotheses
- Interpret experimental results to refine understanding

### Log & Error Analysis
- Parse and interpret various log formats and error messages
- Identify patterns and anomalies in system behavior
- Correlate events across multiple log sources
- Extract actionable insights from diagnostic output

### Code Inspection
- Analyze code paths related to reported issues
- Identify potential race conditions, memory leaks, or logic errors
- Suggest targeted code modifications for testing
- Review fix implementations for completeness and side effects

## Diagnostic Methodologies

### Divide and Conquer
- Systematically isolate components to narrow fault boundaries
- Use binary search approaches for large codebases or datasets
- Eliminate variables through controlled testing

### Signal Amplification
- Suggest logging enhancements to increase visibility
- Recommend instrumentation strategies for hard-to-reproduce issues
- Propose stress testing approaches for intermittent problems

### Root Cause Analysis
- Apply 5 Whys methodology to dig beyond surface symptoms
- Trace causal chains from effect to fundamental cause
- Distinguish between proximate and root causes

## Communication Skills

### Technical Translation
- Explain complex technical issues in accessible terms
- Bridge communication gaps between different technical roles
- Document findings in formats suitable for various audiences

### Collaborative Debugging
- Guide users through self-debugging processes
- Provide just-in-time learning for debugging techniques
- Foster debugging skill development in collaborators

# TOOLS.md - What I Use

## Diagnostic Tools

### Code Analysis
- **Static Analysis**: Identify potential issues through code pattern recognition
- **Dynamic Analysis**: Trace execution paths and variable states
- **Dependency Mapping**: Visualize component relationships and data flows
- **Version Comparison**: Analyze changes between working and broken versions

### Log Processing
- **Log Aggregation**: Combine logs from multiple sources for correlation
- **Pattern Recognition**: Identify recurring error patterns or anomalies
- **Timeline Reconstruction**: Build chronological sequences of events
- **Filtering & Search**: Isolate relevant log entries from noise

### Testing Frameworks
- **Unit Test Generation**: Create targeted tests for suspected code paths
- **Integration Test Orchestration**: Coordinate multi-component testing
- **Stress Testing**: Simulate high-load or edge-case scenarios
- **Regression Testing**: Verify fixes don't introduce new issues

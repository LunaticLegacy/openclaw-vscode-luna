# 券商对比与手续费记录模板

> 这个文件用于记录你自己确认过的券商方案和费用口径。
>
> 不要把这里当作长期有效的公开资料库。手续费、规费、税率、融资利率和活动政策都可能变化，必须标注来源与确认日期。

## 使用规则

- 只写已经核验过的信息
- 每条记录都带上确认日期和来源
- 如果同一券商有多个账户方案，分开写
- 费率变更时保留旧记录，不要直接覆盖

## 建议记录字段

| 字段 | 说明 |
|------|------|
| 券商 | 券商名称 |
| 账户类型 | 普通 / 两融 / 港股通 / 美股等 |
| 市场 | A 股 / 港股 / 美股 / 期货 |
| 佣金 | 协商后的佣金口径 |
| 最低收费 | 每笔最低收费 |
| 规费 / 平台费 | 是否另收、是否已包含 |
| 税费 | 适用市场的税费说明 |
| 融资利率 | 如适用 |
| 联系人 / 渠道 | 客户经理、App、官网等 |
| 确认日期 | 最后一次核验日期 |
| 来源 | 合同、开户链接、聊天截图、官网公告等 |
| 备注 | 免五限制、活动门槛、附加条件等 |

## 核验清单

在把某个费率写进策略或复盘前，先确认：

- 这是默认费率还是协商费率
- 最低收费是否会改变小单真实成本
- 规费是否已经包含在佣金里
- 税费适用于哪个市场、哪一侧交易
- 是否存在活动期、资产门槛或账户限制
- 信息是官网口径、客户经理口径，还是历史截图

## 复盘建议

如果交易成本显著影响策略结果，复盘时至少补一句：

- 使用的成本口径是什么
- 何时确认过
- 如果口径偏宽或偏松，会如何影响结论

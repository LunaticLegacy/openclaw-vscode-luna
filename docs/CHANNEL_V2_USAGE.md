# OpenClaw Luna - 频道 V2 使用指南

## 概述

频道 V2 引入了**层级结构**、**外部数据源集成**和**内容聚合**功能，让频道管理更加强大灵活。

## 核心功能

### 1. 层级频道结构

```
📁 产品团队
├── 💬 需求讨论
├── 💬 技术方案
│   ├── 📎 后端架构
│   └── 📎 前端实现
└── 📊 周报汇总
```

- **Root 频道** (📁): 纯容器，用于组织子频道
- **Standard 频道** (💬): 标准聊天频道
- **Thread 频道** (📎): 子线程，继承父频道配置
- **Aggregate 频道** (📊): 自动聚合多个子频道内容
- **External 频道** (📡): 接入外部数据源

### 2. 创建频道

#### 基础创建
1. 点击 "New Channel" 按钮
2. 填写名称、描述
3. 选择绑定的 Agent
4. 保存

#### 创建子频道
1. 点击父频道的 ⋯ 菜单
2. 选择 "New Subchannel"
3. 配置后保存

子频道会自动继承父频道的 Agent（可配置）。

### 3. 外部数据源

支持接入以下数据源：

| 数据源 | 需要的配置 |
|--------|-----------|
| RSS | Feed URL |
| YouTube | Channel ID + API Key |
| GitHub | Repo 列表 + Token (可选) |
| Webhook | Secret Key |

#### 配置步骤
1. 创建或选择频道
2. 点击 ⋯ → "Add External Source"
3. 选择提供商
4. 填写配置和 API Key
5. 设置同步频率
6. 保存

数据会自动同步到频道聊天中。

### 4. 聚合频道

聚合频道自动收集并展示多个子频道的内容。

#### 配置步骤
1. 创建或选择频道
2. 点击 ⋯ → "Set as Aggregate"
3. 选择要聚合的源频道
4. 选择内容转换方式：
   - **None**: 原样展示
   - **Summary**: 简单截断摘要
   - **AI Summarize**: AI 智能总结
5. 设置聚合频率
6. 保存

### 5. 频道管理操作

| 操作 | 方式 |
|------|------|
| 排序 | 右键菜单 → Move Up/Down |
| 移动 | 右键菜单 → Move to... → 选择新父频道 |
| 归档 | 右键菜单 → Archive |
| 删除 | 右键菜单 → Delete |

#### 删除选项
- **移动子频道到父级**: 保留子频道，上移一级
- **移动到根级**: 保留子频道，变为顶级频道
- **递归删除**: 删除频道及其所有子频道

### 6. API Key 安全存储

所有 API Key 使用 VS Code 的 SecretStorage 加密存储，不会以明文保存在配置文件中。

## 注意事项

1. **Agent 继承**: Thread 类型频道默认继承父频道 Agent，可在设置中关闭
2. **循环引用**: 系统会阻止创建循环的父子关系
3. **归档 vs 删除**: 归档保留历史但隐藏，删除是永久性操作
4. **API 限制**: 外部数据源受限于各平台的 API 配额
5. **同步状态**: 外部源同步状态会显示在频道名称旁边

## 故障排除

### 外部源同步失败
- 检查 API Key 是否有效
- 查看频道旁的同步状态图标
- 点击 "Sync Now" 重试
- 检查 VS Code 输出面板中的错误日志

### 聚合频道无内容
- 确认源频道有消息
- 检查过滤器配置
- 尝试手动运行聚合

### 频道树显示异常
- 点击 Refresh 按钮刷新
- 重启 OpenClaw Luna 面板
